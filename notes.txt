Pour Transporter une variable d'une page à une autre (voir la page chat) :
    On utilise searchParams.get pour récupérer la valeur importée.
    Puis, on ajoute la valeur importé dans une string dans ${} ==> '<p>${valeurImporte}</p>'. 
    Avec innerHTML, en ajoute le string dans une div 


Grid tailwind css: 
    Quand on veut appliquer une position sur tout les grids items ==> place-items-...
    Quand on veut appliquer une position sur un grid item précis ==> place-self-...
    Quand on veut appliquer une position sur un grid item précis avec des positions différentes sur les deux axes ==> justify-self-... pour l'axe horizontal && self-... pour l'axe vertical.

Quand on veut avoir la valeur d'une variable dont la valeur contient .getElementById("") :
    On utilise HTMLInputElement ==> (document.getElementById(elementId) as HTMLInputElement).value

La différence entre ? et ! avec getElementById quand on veut avoir accès à innerHTML:
    On utilise ! quand on est sûr que l'élément existe (renvoi une erreur dans le cas où l'élément est introuvable).
    On utilise ? quand on n'est pas sûr que l'élément existe (plus sécurisée si l'élément est introuvable).

Comment avoir une variable partagée ou unique dans le web socket : 
    Si on veut que la variable soit partagée, on la met en dehors de io.on("connection")
    Si on veut que la variable soit unique pour chaque user connecté, on la met dans io.on("connection")

useEffect :
    Permet d'ajouter du contenu après la compilation de la page 
    (à utiliser avec getElementById pour qu'il détecte l'élément sélectionné).


La différence entre node et nodemon dans package.json : 
    nodemone redémarre l'application à chaque fois qu'il y a un changement dans l'application
